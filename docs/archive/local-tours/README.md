# Local tour pages (taken out 2026-11-13)

The owner asked, while the site moves off WordPress, to remove every page about local tours: the resort has no reliable
local tour operator. Nothing is deleted for good: the pages and every removed piece are kept here, so they can come
back once there is an operator.

## What was taken out

Five pages, with their content and original Elementor CSS moved to this folder:

| URL | Title on the page | Content | CSS |
|---|---|---|---|
| `/sumbawa-indonesia/` | Sumbawa Tours and Day Trips (the "Tour & Activity" menu) | `content/sumbawa-indonesia.json` | `styles/post-10761.css` |
| `/sumbawa-indonesia-tour/agal-waterfall/` | Agal Waterfall, West Sumbawa | `content/sumbawa-indonesia-tour__agal-waterfall.json` | `styles/post-11680.css` |

| `/kalela-waterfall/` | Kalela Waterfall, West Sumbawa | `content/kalela-waterfall.json` | `styles/post-17670.css` |

And from other places:

- The "Tour & Activity" menu group (`src/data/navigation.ts`) and the five paths in `src/data/routes.ts` (so they are out
  of the sitemap) and in `/llms.txt` (`src/app/llms.txt/route.ts`).
- The article `/things-to-do-in-sumbawa-indonesia/` stays (general information about Sumbawa), without the links to the
  tour pages, "Book a guided waterfall trip from the resort", "Guided excursions" (now "Trails lead you through lush
  forest") and the Three Island Tour (quick list line and section).
- `/snorkeling/`: the Three Island Tour under "Our Snorkel Sites".
- The exact HTML of those article and Snorkeling pieces, before and after: `removed-from-other-pages.json`.
- Extra cards (`src/data/extra-content.ts`): the tours text and buttons on `/couples-retreat/` ("Explore together"),
  the "Nature days" card on `/wellness-retreat/`, "waterfall and lake tours" and the Tours button on
  `/host-a-retreat-venue-for-rent-hire/`. The removed text was:
  > A half day at Kalela Waterfall with rice fields and a coconut grove (minimum two people), a full-day Agal Waterfall

- Homepage options A and C (`/home-a/`, `/home-c/`): the tours list on board 5 and the "Trek to Agal Waterfall" frame.

The old URLs redirect (301) to `/things-to-do-in-sumbawa-indonesia/` (`next.config.ts`), and so do the older WordPress
paths that used to lead to them (`/sumbawa-indonesia-tour/`, `/sumbawa-indonesia-tour/danau-lebo-taliwang/`,
`/sumbawa-indonesia-tour/kalela-waterfall/`).

Left in place on purpose, because a restore needs them and nothing reads them while the pages are gone: the pages'
SEO data in `src/data/seo.json` and `src/data/heading-roles.json`, the photos in `public/images/uploads/`, the
original HTML in `docs/audit/source-html/`, and the unused `.tours` styles of homepage option A.

Not changed (general mentions of the scenery, no tour offered or linked): "trek to cascading waterfalls" on the diving
pages, the homepage section "Surf, Waterfalls and Island Tours" and its "Nature" box ("guided tours to waterfalls, local
villages, and scenic lakes"), the couples retreat post ("private excursions to natural wonders like Agal Waterfall"),
and the couples page description in `src/data/seo-overrides.ts` ("waterfall trips"). Change these too if the owner
wants no tour mentioned anywhere.

## Bringing them back

Simplest: revert the commit that took them out (`git log --oneline -- docs/archive/local-tours` shows it), then check
the redirects and the menu.

By hand:

1. Move each `content/*.json` back to `src/content/pages/` and each `styles/*.css` back to `src/styles/elementor/`.
2. Make each page's route again, `src/app/<url>/page.tsx` (e.g. `src/app/sumbawa-indonesia-tour/agal-waterfall/page.tsx`),
   from the generated template (the JSON name and CSS number from the table above):

   ```tsx
   // Generated by scripts/migration/generate-routes.mjs
   import ElementorPage from "@/components/elementor/ElementorPage";
   import type { PageContent } from "@/components/elementor/types";
   import content from "@/content/pages/sumbawa-indonesia-tour__agal-waterfall.json";
   import { pageMetadata } from "@/lib/metadata";
   import "@/styles/elementor/post-11680.css";
   import "@/components/elementor/styles-after";

   export const metadata = pageMetadata("/sumbawa-indonesia-tour/agal-waterfall/");

   export default function Page() {
     return <ElementorPage page={content as PageContent} />;
   }
   ```

3. Add the five paths back to `allPaths` in `src/data/routes.ts` and to the "Explore West Sumbawa" section of
   `src/app/llms.txt/route.ts`.
4. Put the menu group back in `src/data/navigation.ts`, before "Pricing":

   ```ts
   {
     label: "Tour & Activity",
     href: "/sumbawa-indonesia/",
     children: [
       { label: "Agal Waterfall", href: "/sumbawa-indonesia-tour/agal-waterfall/" },
       { label: "Rice Field Walk", href: "/sumbawa-indonesia-tour/rice-field-walk/" },
       { label: "Danau Lebo Taliwang", href: "/sumbawa-indonesia-tour/danau-lebo/" },
       { label: "Kalela Waterfall", href: "/kalela-waterfall/" },
     ],
   },
   ```

5. Remove the redirects to the article from `next.config.ts`, and point the two older WordPress paths back:
   `/sumbawa-indonesia-tour/danau-lebo-taliwang/` to `/sumbawa-indonesia-tour/danau-lebo/`, and
   `/sumbawa-indonesia-tour/kalela-waterfall/` to `/kalela-waterfall/`.
6. Put back the pieces of the article and the Snorkeling page from `removed-from-other-pages.json` (each entry has the
   text that was there and what replaced it), and the tour cards in `src/data/extra-content.ts`.
7. Check the tour details (prices, minimum people, durations) with the new operator before publishing them again.
